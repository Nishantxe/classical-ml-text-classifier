CSV needs a header row with text and label columns (label: fake/real or 0/1; for the common Kaggle Fake/True dataset, merge them and add a label column). The built-in set is a small demo corpus, so treat results as an illustration of the method, not a fact-check. For real use, retrain on a large dataset such as ISOT or LIAR.

Classical ML only: unigram + bigram TF-IDF (sublinear tf, L2 norm) → Passive Aggressive (PA-I) binary classifier. Static site, no server.
